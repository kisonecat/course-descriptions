\begin{Purpose}
This course develops problem solving skills with little emphasis on
theory. Students should be able to solve the PDE's and ODE's and
interpret the solution.
\end{Purpose}

\begin{Text}
\emph{Partial Differential Equations \& Boundary Value Problems}, 11th
OSU Custom Edition, by Boyce, published by Wiley, ISBN: 9781119805113

This text is only available as an eBook

\end{Text}
