## Catalog Description

Homogeneous and non-homogeneous difference equations, Markov chains,
graph theory, network flows, linear programming.

## Prerequisite

{C- or better in 2568 or 5520H; and C- or better in 4530, 5530H or Stat
420}; or {credit for 568, 571, or 520H; and credit for 530, 531H, or
Stat 420}.

### Exclusions

Not open to students with credit for 578.

## Topics List

1.  Homogenous and non-homogeneous difference equations.

2.  Application of Markov chains with absorbing and non-absorbing
    states, limiting behavior.

3.  Hidden Markov models.

4.  Graph theoretical algorithms, network flows, applications.

5.  Linear/integer programming.

## Comment

This course requires the student to use a programming language chosen by
the instructor to complete required coursework. Prior programming
experience is not required.

## Suggested Schedule

- **Week 1.** Difference equations; first-order models; programming setup.
- **Week 2.** Homogeneous linear difference equations; characteristic roots.
- **Week 3.** Non-homogeneous difference equations; systems.
- **Week 4.** Markov chains: transition matrices, states, classification.
- **Week 5.** Non-absorbing chains; stationary distributions and limiting behavior.
- **Week 6.** Absorbing chains; expected absorption times. *Midterm I.*
- **Week 7.** Hidden Markov models; the forward algorithm.
- **Week 8.** Hidden Markov models: Viterbi decoding and parameter estimation.
- **Week 9.** Graphs, trees, shortest paths, and search algorithms.
- **Week 10.** Network flows; max-flow min-cut.
- **Week 11.** Matching and assignment; applications. *Midterm II.*
- **Week 12.** Linear programming; the simplex method.
- **Week 13.** Duality and sensitivity analysis.
- **Week 14.** Integer programming; project work.
- **Finals week.** Final examination or project presentations.
