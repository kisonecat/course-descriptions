\begin{Purpose}
Math 3607 is a course which has three main goals: it introduces students to MATLAB (or improves their knowledge of MATLAB); it uses MATLAB to solve practical problems from various areas of mathematics, physics, engineering, business, and finance; and it presents the numerical analysis needed to use MATLAB effectively. The principle underlying this course is that the way to learn MATLAB and numerical analysis is by doing it, not by reading about it. This course is taught in a computer lab and MATLAB will be used to some extent every class.
\end{Purpose}

\begin{Text}
Learning MATLAB, Problem Solving, and Numerical Analysis through Examples, by Ed Overman (downloadable e-book).
\end{Text}

\begin{TopicsList}
\item MATLAB as a scalar calculator, round-off errors, debugging.
\item Arrays in MATLAB, probability theory, Markov processes.
\item Graphics in MATLAB, applications of probability theory, histograms.
\item Programming in MATLAB, more probability theory, mathematical biology.
\item Function m-files in MATLAB, more Markov processes, chaos.
\item More about functions, randomness.
\item Solving linear systems of equations.
\item Interpolation and approximation.
\item The solution of nonlinear equations and unconstrained optimization.
\item Numerical differentiation and integration
\item Time-evolution ordinary differential equations, boundary-value ordinary differential equations, stochastic differential equations, examples from many disciplines.
\item Eigenvalues, Fourier series.
\end{TopicsList}
